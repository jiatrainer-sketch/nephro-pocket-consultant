# Reel EP.002 — "คุณยายล้มในห้องน้ำ" 🎬

สคริปต์ Python + moviepy สร้างวิดีโอ **Facebook Reel** แนวตั้ง 720×1280 ยาว 30 วินาที
เพื่อรณรงค์การปฐมพยาบาลเบื้องต้น (ผู้สูงอายุล้ม / ศีรษะกระแทก) และโปรโมต
**JIA Trainer Center — CPR & First Aid**

> ⚠️ ส่วนนี้เป็น **เครื่องมือทำสื่อการตลาด/ให้ความรู้** ไม่เกี่ยวกับ logic ทางคลินิกของแอป
> Nephro Pocket Consultant และไม่ได้แตะไฟล์ในโฟลเดอร์ `src/` แต่อย่างใด

## ติดตั้ง

```bash
pip install -r requirements.txt
# ต้องมี ffmpeg ในเครื่องด้วย เช่น
#   macOS:   brew install ffmpeg
#   Ubuntu:  sudo apt install ffmpeg
#   Windows: winget install Gyan.FFmpeg
```

## โครงเรื่อง (7 scene / 30 วิ)

| เวลา | ฉาก | เอฟเฟกต์ |
|------|-----|----------|
| 0–4 | รูปคุณยาย + "คุณยาย 78 ปี ล้มในห้องน้ำ..." | Ken Burns zoom, fade in |
| 4–7 | "⚠️ ห้ามรีบพยุงลุกทันที!" (แดง) | กระพริบ 2 ครั้งแล้วค้าง |
| 7–10 | "📞 โทร 1669 ทันที" (เหลือง) | slide in จากซ้าย |
| 10–14 | 4 ข้อควรทำ เผยทีละบรรทัด | fade in ทีละข้อ ห่างกัน 1 วิ |
| 14–20 | บทเรียน (พื้นน้ำเงิน #1B2A4A) | fade in |
| 20–25 | CTA — เรียน CPR & First Aid | fade in |
| 25–30 | ช่องทางติดต่อ LINE / โทร | fade out ช้า ๆ |

**เพลง:** loop ให้ครบ 30 วิ, ระดับเสียง 20%, fade out 3 วินาทีสุดท้าย

## ปรับแต่ง

แก้ข้อความ/สี/ตำแหน่ง/เวลา ได้ในฟังก์ชัน `build_scenes()` ของ `make_reel_ep002.py`
ค่าสีสำเร็จรูป (`WHITE`, `RED`, `YELLOW`, `ORANGE`, `GREEN`, `BLUE_BG` …) อยู่ต้นไฟล์

ตัวเรนเดอร์ข้อความรองรับ **ภาษาไทย** (จัดสระ/วรรณยุกต์ถูกต้องผ่าน libraqm) และ
**emoji** (fallback ไปฟอนต์ Noto Emoji ให้อัตโนมัติ รวมถึง keycap เช่น 1️⃣2️⃣3️⃣) พร้อมเงานุ่ม
